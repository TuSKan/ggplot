# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly by emailing the maintainer directly or by opening a
[private security advisory](https://github.com/TuSKan/ggplot/security/advisories/new)
on GitHub.

**Please do NOT open a public issue for security vulnerabilities.**

## Response Timeline

- **Acknowledgment**: within 48 hours
- **Fix timeline**: critical issues within 7 days
- **Disclosure**: coordinated after fix is released

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| latest  | ✅                 |
| < v0.1  | ❌ (upgrade)       |

See [CHANGELOG.md](CHANGELOG.md) for security-related fixes.
